
### Step-by-Step: Monitoring Any Fresh Project

  Whenever you create a fresh project directory (e.g., my_java_app), follow these 3 simple steps:

  #### Step 1: Register Your Project

  Run this one command from the repository root:

    python3 copilot.py add my-java-app my_java_app/app.log

  (Alternatively, you can manually paste these 2 lines into projects.yaml):

      - id: my-java-app
        log_file: my_java_app/app.log
  │ The background daemon will automatically detect and start tailing my_java_app/app.log within 2 seconds.
  ──────
  #### Step 2: Run Your Application

  Run your Java or Python app and redirect its output to your configured log file:

  For Java (Main.java):

    cd my_java_app
    javac Main.java
    java Main >> app.log 2>&1

  For Python (main.py):
    cd my_java_app
    python3 main.py >> app.log 2>&1

  (Or configure your logging framework like Log4j, SLF4J, or Python logging to write to app.log).
  ──────
  #### Step 3: View Incident & Apply Remediation

  1. Open the dashboard at http://localhost:8000.
  2. As soon as the error fires, the incident ticket pops up in the Command Queue.
  3. Click the ticket to see:
      • Root Cause & Stack Trace
      • Synthesized Git Diff Remediation Patch
      • ⚠️ What NOT to do (Learned from past traces)
  4. Feed the incident context directly to Claude Code or Cursor:
    curl -s http://localhost:8000/api/v1/tickets/INC-104/context.md | claude

  ──────
  ### Background Service Management

   Command                                                                         | Purpose
  ---------------------------------------------------------------------------------|--------------------------------------------------------------------------------
   python3 copilot.py list                                                         | List all monitored projects and log file statuses
   python3 copilot.py add <id> <log>                                               | Register a fresh project directory
   python3 project_watcher.py                                                      | Run the watcher daemon in the foreground
   ./start.sh                                                                      | Launch the entire copilot platform and watcher in the background
   ./stop.sh
